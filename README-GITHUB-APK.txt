KNOWLEDGEVERSE 2500 — GitHub APK BUILD

1. Create a new GitHub repository named KnowledgeVerse-2500.
2. Upload EVERYTHING inside this folder to the repository ROOT.
3. Root must show: app, .github, build.gradle, settings.gradle, gradle.properties.
4. Commit to the main branch.
5. Open the Actions tab.
6. Open “Build KnowledgeVerse APK”.
7. Click “Run workflow” (or it will run automatically after push).
8. Open the completed green workflow run.
9. Scroll to Artifacts and download “KnowledgeVerse-APK”.
10. Extract it and install KnowledgeVerse-2500-GK-India-Fixed-Rahul-Singh.apk.

Requires internet at runtime for online quiz questions.
